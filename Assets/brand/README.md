## 使用规则（§2.3 摘要）

1. 主品牌锁定 = 图形 + KeyInsight 英文；图形独立版仅用于 App/任务栏/托盘。
2. 浅色背景用深海蓝字标 + 蓝色图形；深色背景用白色字标 + 高对比图形。
3. 图标四周至少保留图标宽度 **12%** 的安全留白；不得拉伸、倾斜、添加额外
   描边或改变 K/I 结构。
4. 16-24px 托盘版本独立简化：保留 KI 主体轮廓，减少渐变、切面、信号弧线细节
   （见 Tray_Mono：只保留一条弧线）。
5. 信号弧线表达设备感知/数据采集/洞察反馈，**不得解读为 Wi-Fi/无线专属**。
